# Business KPI Dictionary

Mapping technical metrics to dashboard language:

- probability_late -> **Delay Risk**: The chance this shipment will miss its contractual target.
- severity_p50 -> **Expected Delay**: The median forecast of days delayed.
- severity_interval_90 -> **Uncertainty Interval**: The range within which the delay will fall 90% of the time.
- predictive_drivers -> **Risk Factors**: Contextual variables heavily associated with delays (not necessarily causal).
- causal_candidates -> **Causal Hypotheses**: Verified topological associations highlighting actionable systemic links.
- simulated_net_benefit -> **Expected Benefit**: Financial quantification of the recommendation scenario vs doing nothing.
