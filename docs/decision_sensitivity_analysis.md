# Decision Sensitivity Analysis

Because costs are simulated, we evaluate robustness by varying delay costs (-) and expedite costs (-).

Decisions are classified as:
- **ROBUST**: Recommendation holds under all cost variations.
- **SENSITIVE**: Recommendation changes depending on cost assumptions.
- **UNSUPPORTED**: Recommendation is no longer chosen in any variation.

This prevents the business from blindly trusting a single cost-assumption simulation.
